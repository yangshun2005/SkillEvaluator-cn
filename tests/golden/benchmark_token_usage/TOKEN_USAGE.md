## Token 用量

实测的 Agent Token 用量。不计分，也不改变任何分数或判定。Token 数为提示词加补全；提示词 Token 包含缓存 Token，不重复计入。评分前失败的尝试也计入。部分总计只覆盖有 Token 计数的尝试，不做任何估算。变化量为使用技能减去基线，以基线占比表示，且需要两组中相同尝试的完整计数。

| Agent | 用例 | 使用技能 | 基线 | 变化 | 实测尝试 |
|---|---|---:|---:|---:|---|
| Claude Code | 全部用例 | 3,300 | 50,072 | 不适用 | 技能 2/2；基线 2/2（1 个未计分） |
| Codex | 全部用例 | 1,210 | 1,650 | -440 (-26.7%) | 技能 2/2；基线 2/2 |
| 全部 Agent | 全部用例 | 4,510 | 51,722 | 不适用 | 技能 4/4；基线 4/4（1 个未计分） |

实测尝试：各组中预期尝试里有 Token 计数的数量。未计分尝试在评分前失败。

- Claude Code：无变化：基线不完整（2 次尝试中 1 次计分）。
- 全部 Agent：并非每个 Agent 都有 Token 变化，因此全部 Agent 合计无变化。
