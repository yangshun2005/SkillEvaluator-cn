**目标：** 处理用户对 PR #560 的后续反馈，恢复可见的原生报告功能，然后更新同一分支和 PR。

**设计：** 原生报告模板仍是展示基线。保留其标题字号、版本标识、整合后的人类可读维度/基线对比、部分对比标注、可点击的代理评分卡和 Harbor 操作。保留此前简洁的 Insights 和已关闭例程的来源信息；减少杂乱不得移除有用的原生视图或操作。用户的明确后续反馈优先于上一修订版中的紧凑标题和被移除的评分卡。

**架构：** 现有的已评估展示数据供给单一 HTML 模板。仅为不可用的已配置维度和自定义指标对比添加有界、带类型的展示投影。在现有 URL 规范化辅助函数中修复 Harbor 回退逻辑。保留的 Tier 3 对象、评分、门禁、支持的后端和 CLI 行为保持不变。CLI JSON 校验器行新增记录的布尔值 `optional_skip`，保留的读取器可往返读写该字段。

**相对此前公开布局的有意变更：** 可点击的层级卡片取代左侧边栏和粘性移动端层级栏。包含 Tier 3 的报告默认使用深色，其他默认使用浅色，而非跟随设备主题；已保存的浅色、深色和系统选择优先。简洁的失败运行 Insights 仅存在于渲染器中；新持久化的失败文本保持不变。

## 约束与审查重点

- 恢复原生整合对比和 Overall 行，使用已记录的公开评分/提升权威数据。绝不重新计算评分或替换为不同的评分公式。
- 不完整的运行显示已配置的标准维度，值为不可用。仅自定义评估显示其记录的指标，绝不伪造五维评分网格。
- 保留缺失/零/不适用、部分对比说明、失败代理范围、来源拒绝、激活限制和基线资格。
- 即使没有时间戳也显示渲染器的 SkillEvaluator 版本，且仅显示已记录的 SkillSpector 版本。模型 ID、路径和例程来源信息保持低调。
- Harbor 操作使用现有已验证 URL，保留所有记录的作业/运行分析，在层级卡片内支持键盘操作，绝不推断私有查看器 URL。
- 保持原生 CSS 声明完整；移除紧凑覆盖，仅保留必要的响应式/无障碍新增。允许更大的标题，但不将报告内容隐藏在粘性界面元素之后。
- 保持转义/脱敏、有限数字、URL 验证、边界、精确保留的下载、离线资源、无 JS、打印、搜索和深层链接完整。
- 不启动新的提供方、评估或重新评分；私有来源报告和截图保持被忽略。
