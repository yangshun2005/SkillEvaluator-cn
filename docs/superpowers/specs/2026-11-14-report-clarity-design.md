# 报告清晰度与完整记录遥测

用户已批准的设计：保留原生三层报告呈现及其功能，合并重复的卡片和文字，并让常规 Run Details 与来源信息低调可用。本设计延续同一分支上的报告对等工作。

有意的公开布局变更：层级卡片取代左侧边栏和移动端吸顶层级栏。含 Tier 3 的报告默认深色，其余默认浅色，不再跟随设备主题；已保存的浅色、深色和跟随系统选择优先。CLI JSON 在验证器行中新增记录布尔值 `optional_skip`，并在保留报告中往返传递；保留的 Tier 3 对象保持不变。简洁的失败运行 Insights 仅在渲染器层实现，保留新持久化的失败文本。

## 内容归属

| 界面 | 首屏可见 | 详情归属 |
| --- | --- | --- |
| 页眉 / 主视觉 | 品牌、目标名称、一项必需验证结果、简短原因、独立的发布状态 | 常规目标路径/配置/版本/配置项放在默认收起的 Run Details；发布原因放在展开区 |
| 层级导航 | 一组可点击的原生层级卡片，含状态和一条有用标题 | 保留旧锚点、键盘导航和显式未运行范围 |
| Tier 1 | 完成度、严重性层级、可操作发现和原生视图 | 被动清单和扫描器来源放在展开区 |
| Tier 2 | 原生 Intra/Inter 标签页、完成度和发现 | 目录元数据和单独的跳过/不完整记录；不提供不可用值卡片网格 |
| 概览 | 简短范围状态、含 agent 的 Score、Lift、Coverage、一项记录操作 | 完整结论和建议放在 Insights；对比和 agent 证据仍可访问 |
| Insights | 完整原生卡片、来源/严重性、操作、验证和证据 | 长记录文本保持完整；说明图例可折叠 |
| Agent Details | 所选 agent 覆盖率、维度和评估器证据 | 被动加载/组件/MCP 详情放在展开区 |
| Trials | 试验/可靠性结果和记录资源 | 完整 token 核算、延迟、成本、图表和方法放在原生展开区 |
| Dataset | 原生可筛选用例卡片、提示和预期 | 单用例尝试诊断默认收起；共享失败只引用一次 |
| 诊断 | 紧凑诊断导航和下载 | 完整错误、路径/复制控件、原始数据、来源证据和限制 |
| Run Details | 一个默认收起的页脚展开区 | 常规身份/环境/模型/摘要/CI/门禁元数据 |

保留判定、分数、最佳 agent 和 lift 能力：判定变为范围状态，分数和最佳 agent 共用一个卡片。概览最多三个主要指标卡片：Score、Lift、Coverage。若所有质量测量均缺失，使用一个明确的不可用状态加覆盖率/操作，而非空的 Score/Lift 卡片。次要目标/检查/安全结果在有记录时以紧凑对比表提供。

被动插件区块保留其归属、内容和锚点。默认收起；空观察可共用一个紧凑分组，每个保留区块仍可寻址。对省略行、缩短显示文本和保留前无法恢复的裁剪保留可见限制提示；导出不会恢复此前缺失的文本。

## 记录遥测兼容性

规范的原生形状 `token_usage` 和 `latency_metrics` 仍保留，但当前仅总计/原生试验适配器未完整呈现。恢复可读的 dataset/agent/case 和 with-skill/baseline 表格、prompt/cached/uncached/completion/total/efficiency token、增量/原因/覆盖率、计时来源、LLM/工具秒数、ms/token 和 arm 运行时。保留较新的公开 `agents[*].resources` 路径。

使用有界只读显示适配器；不调用收集器、不重新打开源、不重新评分、不变更规范数据、不计算替代计时、不放宽可比性门禁。原生 token 图表用 uncached prompt + cached prompt + completion 对比两种条件，不重复计算缓存读取。未知/部分计数器保持未知/部分。记录的比较不可用原因仍显示在其值旁。

## 验收

- 每条记录的 insight 对应一张完整 Insights 卡片；概览提供简洁摘要/操作和原生链接。
- 无默认展开的空插件面板、重复层级导航、重复主视觉分数块或空质量卡片墙。
- 必需验证、实时质量、已完成 agent 范围、发布和执行状态保持区分。源拒绝、不完整 arm、从未激活的技能、临时证据、历史基线和无效对比在受影响结果处保持可见。
- 在 390 x 1000 下打开 Tier 3 概览，在常规元数据前显示状态、已评分/计划覆盖率和记录的下一步操作。全尺寸页眉随页面滚动；保留 16px 原生正文缩放。
- 在审计的不完整和成功形态上，概览默认说明文字至少减少 40%。绝不裁剪作者证据或隐藏必要限定以满足目标。
- 常规 Run Details 保持收起；方法、运行 ID、摘要和路径不先于主要结果。一条约 15 词的共享注意提示链接到完整的范围特定原因。
- 所有原生功能、筛选器、展开区、链接/复制/下载操作和六个 Tier 3 标签页保持可用。深链接显示所属标签页和收起的祖先；搜索显示折叠匹配。保留打印状态恢复、无 JS、离线图表、两种主题和移动端溢出处理。
- 保留分数、门禁、规范载荷/下载相等性、源行/投影、保留的 optional-skip 元数据、CI 规范产物链接、边界、转义、脱敏、安全 URL、代理项处理和原子输出保护。
- 重放保留报告，零提供方调用/重新评分试验；保留覆盖率 28/36 和 12/20。仅提交合成夹具。在检出目录外验证已安装 wheel 行为，并如实报告无关的基线失败。

## 选定方案

每个事实只有一个主要归属，配简洁摘要和原生展开区。仅改措辞会保留结构重复；单独的紧凑/详细模式会增加冗余 UI 和维护。保留一个渲染器、固定 Chart.js 4.5.1 和原生排版/配色，仅做窄屏无障碍/布局适配。
